Core brand colors

These are the three current core identity colors. Select Copy HEX to copy a color code for design files, CSS, or product interfaces. RGB values are included for tools that request RGB input.

Lime green

Brand accent and visual highlight

#A7E021
RGB 167, 224, 33
--abe-color-lime

Charcoal

Primary dark mark and text on light backgrounds

#111111
RGB 17, 17, 17
--abe-color-charcoal

Off-white

Light mark and text on dark backgrounds

#F9F9F6
RGB 249, 249, 246
--abe-color-off-white

CSS color tokens

:root {
  --abe-color-lime: #A7E021;
  --abe-color-charcoal: #111111;
  --abe-color-off-white: #F9F9F6;
}

These are working brand tokens, not a formally ratified final design-system specification. Supporting banner colors are documented in the repository's color palette.

All logo files and color values are derivatives of the current working brand identity, which has not been independently verified as final master artwork. Email clients should use the fixed PNG variants rather than the adaptive SVG. For full guidance, see the Branding repository.
