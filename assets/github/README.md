# GitHub Brand Assets

Reusable assets for ABE TechLab's GitHub presence.

## Profile banner

- [Profile banner SVG](./abe-techlab-profile-banner.svg)
- Canvas: `1200 × 320` viewBox
- Visual palette: banner charcoal, off-white, lime, and supporting grays
- Current tagline: “Ideas into systems. Systems into impact.”
- Current profile reference: [Organization profile README](https://github.com/ABE-TechLab/.github/blob/main/profile/README.md)

The banner is a purpose-made profile graphic, not a logo master or a universal cover image for every platform. Check cropping and readability before adapting it to a platform with different dimensions.

## Current public copies

The public profile currently uses copies of these assets from the `ABE-TechLab/.github` repository. The private Branding repository is the library copy for internal reference and maintenance; when one copy changes, reconcile both repositories so they do not drift.

- Logo variants: [light](../logos/abe-techlab-mark-light.svg) · [dark](../logos/abe-techlab-mark-dark.svg)
- Banner: [SVG](./abe-techlab-profile-banner.svg)

## Use

Prefer the SVG for compatible web and documentation surfaces. Export raster versions only when the destination requires them, retaining the SVG as the source file. Do not introduce new logo geometry or describe adaptations as official without review.
