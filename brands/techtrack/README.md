# TechTrack Brand Assets

The dedicated source of truth for the standard TechTrack ecosystem.

**Tagline:** Skills Today. Opportunities Tomorrow.

## Source artwork

The supplied mark, horizontal, and stacked SVG files are preserved unchanged in [source/](./source/). Important: these SVG files contain embedded PNG images and have no editable SVG path or text elements. They are image-backed SVG containers, not vector masters.

The logo package includes symbol-only, horizontal, stacked, and wordmark-only assets. The wordmark-only composition is cropped from the supplied stacked logo artwork.

## Exports

Generated files are in [logos/svg/](./logos/svg/) and [logos/png/](./logos/png/).

- Transparent PNG exports and 2× derivatives for each composition.
- Opaque white (#FFFFFF), black (#000000), and lemon (#FFC93D) PNGs for each composition, with 2× derivatives.
- Transparent SVG compatibility wrappers are included for convenience; they contain embedded PNG artwork and are not editable vectors.

The 2× exports are high-density interpolations of the source images. They do not add vector detail beyond the embedded PNG resolution. Use the supplied SVG source as-is for source preservation, or provide the original editable vector design when true vector-quality scaling is required.
